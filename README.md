# Artisanat Tunisien - Projet MEAN Stack

Application web de gestion de produits artisanaux tunisiens realisee a Polytech Monastir.

## Technologies

- Backend : Node.js, Express, Mongoose, MongoDB
- Frontend : Angular 17, Bootstrap 5, SweetAlert2

## Installation Backend

cd backend
npm install
node seed.js
npm run dev

## Installation Frontend

cd frontend
npm install
npm install sweetalert2
ng serve
